We informally characterize ***vectors*** as objects that can be *added* together and *multiplied* by a *scalar*value. Formally, however, **vectors** are what we denominate as ***Groups***. 

Consider a **set** $\mathcal{G}$ and an operation (such as $+$, $-$, $*$, $/$, etc.) $\otimes$ that takes two inputs in the set and produces an output in that same set ($\otimes:\mathcal{G} \to \mathcal{G}$). Then we can define the set equipped with the opera$\mathcal{G}:=(\mathcal{G},\otimes)$
