#Networking #NetworkingBasics
##### *Networking Basics*
---
A **protocol** is a set of rules that determines how messages are sent and received on a network. Protocols allow devices to see the networking environment using a representation of end and intermediary devices.
###### Device Network View
- A device only sees its **own addressing information**.
- A device knows it's on the same network as another device thanks to **network protocols**.
- Most network communications are broken up into smaller data units, or **packets**.

The **IEEE** regulates the ***standards*** for ***wireless communication***, with the **IEEE 802.11** standard governing **WLAN** environments. There are of course amendments to this standard that describe characteristics for other kinds of **wireless communication**.

**Wireless standards** for **LANs** use the 2.4 GHz and 5 GHz frequency bands. Collectively, these technologies are referred to as ***Wi-Fi***.

**Wireless routers** using the 802.11 standard include multiple settings that need to be configured, among the most important are:
- **Network Mode -** The type of technology that must be supported. 802.11b, 802.11g, 802.11n, or *mixed mode*.
- **Network Name (SSID) -** Name used to identify the WLAN.
- **Standard Channel -** Specifies the channel in which communication will occur. Normally set to *Auto* by default to allow the access point to decide the optimal channel.
- **SSID Broadcast -** Determines if the name, or *Service Set Identifier*, will be broadcast to all devices within range.
