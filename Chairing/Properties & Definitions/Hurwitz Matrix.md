#Chairing #Definition 
A ***Hurwitz*** (or stable) ***matrix*** is a **square** matrix whose **eigenvalues** all have *strictly* negative *real* parts. For a $n\times n$ matrix:
$$
\lambda_{i} \text{ satisfy } \mathrm{Re}(\lambda_{i}) < 0
$$
